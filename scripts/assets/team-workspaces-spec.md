# Team workspaces: spec

## Survey

Admins asked for this in the Q3 survey: 41 of 60 want to add and remove members without contacting support.

## Roles

| Role   | Can                             |
| ------ | ------------------------------- |
| Owner  | Everything, and billing         |
| Editor | Write notes in shared notebooks |
| Viewer | Read shared notebooks           |

## Must keep working

- Sign-in through the company's existing SSO.
- Notes made offline still sync once a member is removed: they stay with the author.
