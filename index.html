Questions

Questions, answered.

What is Teamtrail?
A local trail map for big work done by many AI coding agents. It breaks the work into tickets, sends you only the calls that are yours, and counts nothing as done until it's verified.
How do I know the work is really done?
Every point of done needs proof: checks Teamtrail runs itself, a review by an agent on another model, or your sign-off. See Verification.
Which agents does it work with?
Any agent that connects over MCP. One command connects Claude Code or Codex and adds /scout to their chat.
Does Teamtrail run my agents for me?
Locally, never: you start your agents as usual. Teamtrail Cloud, in early access, runs them in sandboxes and opens a pull request per ticket.
Does my data leave my machine?
No. Plans stay in your project folder, or in GitHub or Linear, which your computer talks to directly. Your agents still use their own AI services.
Is it free?
Yes. Teamtrail is free to use and runs on your computer.
How do I install it?
Run npx teamtrail in your project folder (Node.js 20 or newer). Then connect your agent with npx teamtrail connect claude or npx teamtrail connect codex. Pick Demo in setup to look around a ready-made trail first.

Ready to hit the trail?

One command in your project folder. The Lookout opens in your browser and Scout walks you through the rest.
