In early access

What you get today.

Teamtrail Local is built for one person. Cloud adds what matters once the Lookout has to be reachable, and once there are more of you.

  • Your agents, running while you're away

    Turn on Run my agents and Cloud runs Claude Code or Codex on the ready work, each in its own sandbox.

  • Your repositories, through our GitHub App

    Owners pick which repositories agents may work in. Each run gets a short-lived token for one.

  • On your own keys

    Your own Anthropic or OpenAI key. We never resell model usage.

  • Verified, on the commit they pushed

    Your approved checks run on the exact commit an agent pushed, and the proof names it.

  • Paced to your team's review

    No agent starts new work while too many finished tickets wait for review.

  • Verified work merges itself

    Each pull request merges once verified; high-risk or unverified work waits for you.

  • A workspace of its own

    Its own engine, address and storage, backed up daily. Nothing shared.

  • People and roles

    Sign in with GitHub. Owners change settings, members answer and approve, viewers read.

  • High-risk calls, delegated

    Owners make high-risk calls, and can name others who may.

  • Take it home anytime

    Download everything as plain files and carry on with Teamtrail Local, for free.
