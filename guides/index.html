Safe by design

A guide can raise the bar. Never lower it.

Enforced by Teamtrail, not by the guide.

  • No code in a guide

    Instructions and checklists only. Nothing runs when you add one.

  • You approve every check

    A command a guide proposes runs only after you approve it.

  • Pinned and verified

    A guide that changes after you approved it is switched off until you look.

  • Guides only add rules

    It can add checks, never skip review, lower verification or decide for you.

Write your own

Your team's know-how, in one short file.

A markdown file: a checklist and plain steps for the agent, started from a template.

  • 01

    Write it

    teamtrail guides new <id> writes a template. The docs list every field.

  • 02

    Check it

    teamtrail guides lint refuses anything that would steer an agent around you.

  • 03

    Approve it, or share it

    Approve it in Settings → Guides, after every edit too. Or send it to the catalog.
